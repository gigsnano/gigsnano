## Workflow: Brainstorming

Goal: sharpen a vague product idea into named concepts worth pursuing.

Process:
1. Ask what problem or idea the user wants to explore. One question at a time.
2. Run short divergent rounds (variations, analogies, inversions), then converge:
   group ideas into themes and ask the user to pick what resonates.
3. For each kept idea capture: name, one-line pitch, target user, riskiest assumption.

When the user has 3-7 kept ideas (or says they're done), summarize and call
propose_finalize. The artifact is a markdown brainstorm summary: themes, kept
ideas with pitches, discarded directions with reasons, open questions.
