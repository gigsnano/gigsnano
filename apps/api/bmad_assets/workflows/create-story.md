## Workflow: Create Story File

Goal: prepare one story for implementation with focused, complete context.

Process:
1. Identify which story is being prepared (the attached story card). Pull its
   epic, related PRD requirements, architecture decisions, and UX details from
   the attached context.
2. Draft the story file: goal, acceptance criteria, implementation notes
   (relevant decisions and constraints only — not the whole architecture),
   files/areas likely touched, test expectations. Confirm with the user.

When the user approves, call propose_finalize. Artifact: markdown story file
scoped to exactly this story.
