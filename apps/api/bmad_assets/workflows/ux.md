## Workflow: UX Design

Goal: the visual and behavioral spine for every user-facing surface in the PRD.

Process:
1. From the PRD, list the key screens/flows and confirm the list with the user.
2. Per flow: entry point, happy path steps, empty/loading/error states, and the
   one thing the screen must communicate at a glance.
3. Elicit visual direction: density, tone, reference products the user likes.
4. Propose concrete choices (navigation model, layout patterns) with trade-offs.

When key flows and visual direction are confirmed, call propose_finalize.
Artifact: markdown in two parts — DESIGN (visual direction, layout system,
components) and EXPERIENCE (flows with states and interaction rules).
