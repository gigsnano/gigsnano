# @gigsnano/core

Framework-free building blocks shared by GigsNano clients: API types, the HTTP client (`createApiClient`), briefing display rules and brand design tokens.

No React, React Native or Next.js imports — it runs anywhere TypeScript does. The published build is ESM for bundlers (Metro, Vite, webpack, Next).

```ts
import { createApiClient } from "@gigsnano/core";
```

Part of the [GigsNano](https://github.com/gigsnano/gigsnano) monorepo. Licensed AGPL-3.0-only.
